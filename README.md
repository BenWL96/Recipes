# Recipes

A personal recipe collection, recreated from `Recipes.docx` as a static HTML/CSS site.

Live site: https://benwl96.github.io/Recipes/

- `index.html` — home: meal tiles, search across every recipe, all recipes grouped by meal
- `breakfast.html`, `lunch-dinner.html`, `desserts.html` — every recipe for that meal, with type filters (Korean, Japanese, Pasta & Grains, Sides & Sauces…) and search
- `lunch.html`, `dinner.html` — redirects to `lunch-dinner.html` for old links
- `ideas.html` — links and ideas still to try
- `recipes/` — one page per recipe (ingredients + method, previous/next, more from the same meal)
- `assets/` — `style.css` and `app.js` (mobile menu, filters, search)
